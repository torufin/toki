# TOKI

App privée de révision du TOEIC, 100 % hors ligne (remplace l'ancien dépôt « ile-aux-mots »).

Ce dépôt ne contient que la page d'installation de l'app (`index.html`, `sw.js`, `manifest.webmanifest`).

Installation : https://torufin.github.io/toki/ (servie depuis la branche `gh-pages`).
